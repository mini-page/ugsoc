Case Study 01

asllock — Windows Access Control & NTFS TUI

Repository
The Challenge

Administrators frequently corrupt NTFS Discretionary Access Control Lists (DACLs) with manual icacls invocations. Fragile commands lack dry-run validation, and accidental inheritance breaks lead to critical service lockouts or privilege leaks.

The Solution

Engineered a keyboard-driven Terminal User Interface (TUI) interacting directly with the Win32 Security API via .NET. It evaluates ACE canonical order, previews inheritance changes in memory, and provides instant preset profiles (Lockdown, Read-Only, Admin-Exclusive).

The Impact

Reduced folder permission audits from 12 minutes to under 45 seconds. Zero accidental administrative lockouts across hundreds of automated test suites due to atomic pre-flight transaction verification.

Legacy Manual Workflow
  • Multi-step CLI syntax with obscure numeric mask flags (/grant:r).
  • No rollback when operations fail mid-tree on locked files.
  • High risk of unauthenticated write permission inheritance.
asllock TUI Engine
  • Instant single-key preset locks with visual DACL inspection.
  • Pre-commit diff preview of all Access Control Entries.
  • Automated ACL backup prior to executing any write metadata.
C# / PowerShell Win32 Security API NTFS ACLs ANSI TUI
Case Study 02

TheSecretJuice — SecOps Automation & CLI Suite

Repository
The Challenge

Security analysts waste valuable triage time copying outputs between disparate CLI binaries, parsing unstructured strings, and remembering dozens of unrelated command-line parameters during incident escalation.

The Solution

Architected an extensible PowerShell module suite providing standardized pipeline-driven cmdlets. Unified recon sweeps, hash verification, DNS inspection, and privilege checks under a single cohesive syntax with tab completion.

The Impact

Replaced over 20 disparate scripts with one unified module. Enabled structured JSON streaming directly into incident management systems, accelerating standard host triage by 65%.

PowerShell Core Pipeline Architecture Incident Triage JSON Streams
Case Study 03

SyncMaster — Enterprise Backup & Robocopy Orchestrator

Repository
The Challenge

Windows Robocopy is famously resilient but completely lacks graphical visibility, error alerting, real-time progress feedback, or smart exclusion of dangerous junction loops and volatile temp caches.

The Solution

Created a lightweight orchestrator with multi-threaded mirror queuing, automatic permission preservation flags (/COPYALL), VSS volume shadow copy integration, and automated verification hash checks.

The Impact

Zero data loss during multiple high-capacity volume migrations. Automatic retry queues with exponential backoff prevent network timeouts from failing multi-terabyte synchronization jobs.

Robocopy Engine Volume Shadow Copy (VSS) Delta Mirroring Multi-Threading
Case Study 04

Cleanify — Privacy-First Android Optimization Engine

Repository
The Challenge

Commercial Android "cleaner" applications are notorious privacy liabilities: injecting intrusive ad telemetry, uploading file indexes to remote servers, and demanding invasive root permissions.

The Solution

Engineered a 100% offline cleanup utility adhering strictly to modern Android Scoped Storage paradigms. Implemented zero-telemetry local perceptual hashing to detect duplicate photos and residual cache without external network requests.

The Impact

Reclaims an average of 3.2 GB of storage per installation with zero user privacy compromise. Operates completely offline with transparent open-source code and zero tracking SDKs.

Android SDK Scoped Storage API Offline Deduplication Privacy Engineering
